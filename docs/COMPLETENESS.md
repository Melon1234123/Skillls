# 本机文件完整性核对

核对范围为本机 `.codex/skills`、`.agents/skills`、`.codex/plugins/cache` 及技能依赖的 ARIS 源码目录。

| 核对项 | 结果 |
| --- | --- |
| 本机纳入范围的文件路径（含目录链接展开内容） | 5547 |
| 原始文件映射与 SHA-256 | 5547 条，逐项与源文件及仓库副本比对通过 |
| 当前 155 个技能入口 | 108 本地 + 41 插件 + 6 系统，实际文件全部存在 |
| 插件缓存版本目录 | 21 个，归档为 20 个不同路径；内容相同的别名共用副本 |
| 共享目录差异版 | 14 个，与 Codex 本地版分别保留 |
| 未映射/哈希不一致 | 0 |

当前清单中的 11 个插件完整归档于 `plugins/`；其他包和旧版本归档于 `archive/plugins/`。原始本地技能文件在 `archive/local/`，系统技能在 `system-skills/`。`skills/` 中保留便于迁移的修复版本，因此原文和修复版分别存在。

## 明确排除

- 用户要求删除的数学建模比赛（含附带工具和参考资料）、天文 `run-starskill`。
- Git 内部历史、Python 缓存、系统杂项、虚拟环境和 node_modules。
- 私有 `.env` 文件；账户配置、认证、密钥、浏览器状态、聊天、个人记忆不在扫描上传范围。

逐文件记录见 [local-files.json](../manifests/local-files.json)，包版本见 [skills.json](../manifests/skills.json)。文件完整性不等于云端工具服务或账号已恢复。未在其他 agent 上实际验证的加载能力仍需在目标机核对。
