# 内容核对表

以用户原图或已经逐项核验的中间版为准。OCR 可辅助，但不能代替看图；清晰的生成图也可能包含错误答案或错边。

## 文字与公式

- 原图可见内容是否完整，边缘是否被裁切？
- 题号、行数、词句、数字和符号是否对应？
- 上下标、大小写、集合元素及其顺序是否改变？
- 0/1、z/2、q/g、ε/∅ 等是否误认？
- 表格的每个值是否仍在原来的行列，空白是否被擅自填充？
- 原图不一致之处是否被“智能纠正”？如果不是解题任务，应保留并注明不确定性。

## 状态图及其他有向图

为每幅图分别核对：

| 项目 | 核对方式 |
| --- | --- |
| 节点 | 列出名称，逐个数一遍，查重和查漏 |
| 起点 | 起始箭头是否仍指向同一节点 |
| 终态 | 单圈/双圈是否逐个匹配 |
| 边 | 按 (起点, 标签, 终点) 三元组逐条对照 |
| 回边 | 两端箭头尖数量、方向，是否意外变双向 |
| 自环 | 归属节点、标签和可见箭头尖是否保留 |
| 交叉 | 线条相交是否被误画成节点，标签是否串到别的边 |

“表格正确”不代表旁边的图正确；两者分别检查。不要基于理论补画原图没有的死状态或转移。

## 风格与成品

- 笨拙程度是否符合最新反馈，还是仍像漂亮手写字体？
- 不规则是否体现在字形结构和间距，而不只是统一的波浪线？
- 文字可读，图线与文字不粘连，黑底白字没有混入装饰色？
- 所有目标页都已交付，编号顺序与输入一致？
- 局部修复是否引入新的缺字、重复符号或单双圈变化？

只报告实际检查过的范围。生成图片没有可自动证明内容等价的保证；若仍有不确定内容，明确指出具体位置。
